Game Title: Quack Kitchen
Team Name: DigiDucks
Game Concept:
Quack Kitchen is a 2D top-down cooking-simulation game where players play as a duck who is managing a restaurant for the first time.

How To Play:

1. Controls:
* Movement: WASD
* Pick up/ put down objects: J key
* Cut/ Fry ingredients: Hold K
* Interact with drone: J key
* Menu buttons: Mouse Click


2. Debug functions:
* Toggle fullscreen: Alt+Enter
* View collider outline: P key


3. Cheat functions:
* Add points: N key
* End the level: M key
* Make salad: V key
* Make burger: B key


4. Gameplay:
* Prepare food ingredients by chopping or frying them
* Assemble the required ingredients on a plate and when ready, submit the plate to a serving station to gain points


Features:
Players are able to create and submit 2 orders.
Salad: White plate + Chopped shrimp + Chopped lettuce + Chopped Tomato
Burger: Grey plate + Cooked Meat + Chopped Cheese + Bun


1. Ingredients pickup/put down (Incomplete)
* Able to pick up ingredients
* Incomplete as objects can only be put on tables and not on floor


2. Chopping (Complete)
* Put ingredient on chopping board and hold K to start cutting
* Chopping is completed once the ingredient undergoes a visible change in appearance


3. Frying (Complete)
* Put cut meat on frying pan and hold K to start frying 
* Frying is completed once the ingredient undergoes a visible change in appearance


4. Limited ingredients stock (Complete)
* Ingredients stock is limited and can run out


5. Trash (Complete)
* Able to trash holdable objects


6. Restocking (Incomplete)
* Able to replenish ingredients stock
* Incomplete as interacting with drone resets all stock to the default count (5)
* Interact with the drone (press J on drone) to replenish


7. Ingredients assembly (Complete)
* Able to assemble ingredients on plate


8. Order submission (Incomplete)
* Able to submit completed orders:
   * Salad (press V to generate)
