Configuration Setup:
Debug: Set Quack_Kitchen module as startup project. Then, clean, build solution and run.
EditorDebug: Set LevelEditor module as startup project. Then, clean, build solution and run.
Release: Set Quack_Kitchen module as startup project. Then, clean, build solution and run.
EditorRelease: Set LevelEditor module as startup project. Then, clean, build solution and run.

Projects:
LevelEditor: Handles the level editor backend
DuckEngine: Handles the backend engine
Quack_Kitchen: Handles the game itself

How to turn on/off level editor:
Offline. 
To turn it on, Change configuration to EditorRelease, and Set LevelEditor module as startup project. Then, clean, rebuild solution and run.
To turn it off, Change configuration to Release, and Set Quack_Kitchen module as startup project. Then, clean, rebuild solution and run.
